==========
AngelGuard
==========

* Our project name is AngelGuard. It is an Android app built to send quick emergency alerts without the hassle of unlocking the phone and searching for safety apps during critical moments.

Problem Statement:
------------------
During emergencies, wasting time to unlock the phone and open a safety app can be dangerous. This app helps users trigger alerts instantly.

Key Features:
-------------

Instant emergency alerts using quick shortcuts.

Real-time location tracking.

Automated data sync using Firebase.

Secure PIN protection to stop the alarm.

Tech Stack:
-----------

Language: Kotlin

Platform: Android

Database: Firebase

APIs: Groq API and Android Native Services

How to Run the Project:
-----------------------

Clone the repository to your local machine.

Open the project in Android Studio.

Wait for the Gradle sync to complete, connect your phone, and hit the run button.
